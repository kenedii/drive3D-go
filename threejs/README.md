# Drive3D Three.js Implementation

This is a browser re-implementation of the original Go-based drive3D project to demo on my portfolio. The native Go raylib renderer wasn't portable to the browser, so I recreated the gameplay and procedural chunk generation logic in Three.js (client-side JavaScript) using the same world-generation ideas and seeded randomness.

Demo available at https://ckenedi.vip/drive3d.html
