# drive3D-go
Simple 3D driving game with procedural world generation made in Golang.

Includes different landscapes, such as desert, highway, dirt road, city, ice.

Other features include:
- FPS/Speed toggle in Settings
- Different landscapes and buildings
- Car speeds up when driving over ice

I re-created this using Three.js to be playable in a web browser, a demo is available at https://ckenedi.vip/drive3d.html
